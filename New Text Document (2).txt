Bước 1 — Cài packages Python (pylon SDK đã có sẵn, chỉ cần wrapper):
cd D:\basler_inspect
pip install -r requirements.txt
Nếu pypylon version không khớp với pylon SDK đã cài, hãy chạy pip install pypylon để lấy bản mới nhất tương thích.
Bước 2 — Chụp ảnh mẫu chuẩn (golden sample):
python main.py --capture-reference --reference-out reference.png
Đặt vật mẫu "đạt" vào vị trí kiểm tra trước khi chạy → lưu reference.png.
Bước 3 — Sửa config.json cho khớp camera thực tế của bạn:
- camera.serial_number: null = lấy camera đầu tiên, điền string nếu có nhiều camera
- camera.exposure_time_us / gain_db: chỉnh đến khi ảnh đẹp trong Pylon Viewer
- camera.width/height: khớp với ROI bạn đã set
- inspection.roi: [x, y, w, h] — vùng kiểm tra brightness
- inspection.template_match_threshold: 0.9 = score match ≥ 0.9 → PASS
Bước 4 — Chạy inspection:
python main.py --once                    # Chụp 1 lần, lưu + log
python main.py --interval 0.5            # Chụp liên tục mỗi 0.5s
python main.py --once --no-save          # Chỉ in kết quả, không lưu ảnh
Output
- ./captures/img_<timestamp>_PASS|FAIL.png — ảnh đã annotate (chữ PASS/FAIL màu xanh/đỏ + chi tiết từng check)
- ./results.csv — log mỗi lần chụp: timestamp, overall, score từng inspector, detail
